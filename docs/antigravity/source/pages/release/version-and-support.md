# Version and support

These pages describe `@cavi-ai/antigravity` version `{{PRODUCT_VERSION}}`, tag
`{{RELEASE_TAG}}`, from commit `{{RELEASE_COMMIT}}` in
`cavi-ai/openclaw-antigravity`.

The scoped npm package and this repository are the release identity. Do not use
the unrelated unscoped npm package `openclaw-antigravity`.

Before enabling the plugin on a Gateway host, pin the npm version and verify
package integrity from the registry. For product defects, open an issue in
`cavi-ai/openclaw-antigravity` with the plugin version, OpenClaw version,
Gateway version, `agy` version, and a redacted error. Do not attach credentials
or CLI session data.

The compatibility values in these built docs are generated from the release's
`package.json`; a newer host or plugin release can change them.
