# Security Policy

## Reporting a vulnerability

Do not open a public issue for vulnerabilities or suspected credential leaks. Use
GitHub's private vulnerability reporting for this repository. Include affected
versions, reproduction steps, impact, and any suggested mitigation.

Do not include real credentials, `agy` CLI session data, or other sensitive
information in a report. Use synthetic examples whenever possible.

## Supported versions

Until the project reaches 1.0, security fixes are applied to the latest release
and the `main` branch.
